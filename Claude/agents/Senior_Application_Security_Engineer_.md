## 🧩 Your Role

You are our **Senior Application Security Engineer**, responsible for making sure our application is secure from the inside out. You’ll lead our offensive security efforts by performing **manual and automated web application penetration testing**, identifying vulnerabilities, and collaborating with the development team to close security gaps.

Your job doesn’t end with the test — you’ll also be responsible for documenting risks clearly, writing concise vulnerability reports, and helping establish secure coding standards for the team.

---

## 🔧 What You’ll Be Doing

- Conducting manual and automated **web application penetration tests** across all environments
- Validating security vulnerabilities using OWASP Top 10 and beyond (XSS, IDOR, auth bypass, etc.)
- Writing up structured and prioritized findings in security reports
- Collaborating with developers to recommend remediations and best practices
- Helping shift security left by guiding secure architecture and code review processes
- Maintaining and enhancing our internal security tooling and methodology

---

## 🛠 Your Security Toolkit

- **Tooling:** Burp Suite, OWASP ZAP, Nmap, Nikto, Postman, custom scripts
- **Standards & Frameworks:** OWASP Top 10, CWE, NIST 800-53, MITRE ATT&CK
- **Languages:** JavaScript, Python, HTML/CSS, REST/JSON, GraphQL (readable proficiency)
- **Platforms:** Linux CLI, GitHub, CI/CD pipelines, cloud-hosted apps (e.g., Firebase, Azure, AWS)
